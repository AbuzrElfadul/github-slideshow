# Video Script Pack — "[FIELD] explained in [N] Minutes"

Format analysis of the Wacky Science series (reference video:
[ALL OF PHYSICS explained in 14 Minutes](https://youtu.be/ZAqIoDhornk)) plus original scripts
written in the same format.

| File | What it is |
|---|---|
| [`00-channel-analysis.md`](00-channel-analysis.md) | Why the format works, title engineering, the three-layer hook architecture, the "ladder" scenario template, voice rules, and a ranked list of untapped topics |
| [`01-all-of-math.md`](01-all-of-math.md) | **Full production-ready script**, ~2,400 words / 15:00, with timings and visual directions |
| [`02-human-body.md`](02-human-body.md) | Beat sheet, 16:00 — cold open, all 11 section joins, and close written verbatim |
| [`03-all-of-space.md`](03-all-of-space.md) | Beat sheet, 18:00 — cold open, all 11 section joins, and close written verbatim |
| [`04-hook-and-title-bank.md`](04-hook-and-title-bank.md) | Reusable title formulas, five cold-open patterns, the micro-hook library, six explanation moves, closing formula, production checklist |

All script content is original writing in the style of the format. YouTube was not reachable from
the authoring environment, so the analysis is a reconstruction of the format from channel metadata
and series conventions rather than a transcript-level breakdown of the reference video.
